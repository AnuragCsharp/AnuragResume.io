RUNNING DAILY

I replaced bug-hunting with an AI agent that never sleeps

Slack bug channel → triage → analysis → fix → tracker

Our team used to lose evenings to bug triage. So I built an agent that watches our Slack bug channel. When someone posts a bug, it reacts in about a second, reads the report, digs through the codebase, works out the root cause, and drafts the fix on a branch — then files the whole investigation on a GitHub Projects tracker so nothing gets lost and everything is auditable.

  • It hunts — screenshots, stack traces, reporter chats: it pieces the story together itself.
  • It analyses — root cause written up like a good engineer's post-mortem, not a guess.
  • It fixes — branch, patch, and tests, but merging stays a human decision: mine.
  • It keeps books — every bug lands on the GitHub tracker with status, owner, and evidence.

bug reports acknowledged in ~1 second; tracker maintained on GitHub Projects

IN PRODUCT

Genie — an AI concierge that talks to people

Voice in → intent → action → voice out

Inside HatoHelp I built Genie: you speak to the app — in Hindi or English — and it books your ride, orders your food, finds you help. I engineered the full voice loop (speech recognition → LLM brain → neural speech out) on AWS, and made it provider-swappable so the brain or the voice can be replaced without touching the product. The hard part wasn't the AI — it was the safety: I designed a capability registry so Genie can only do what it's explicitly allowed to do, and money-moving actions always come back to the human.

live voice concierge; typed capability registry; zero unauthorized actions

ZERO RELEASES

A storefront that redecorates itself — no app updates

Server-driven UI · remote layouts · live in minutes

I designed our grocery storefront so festivals are a content change, not a release. Theme, hero, banners, prices, even animations stream from a JSON manifest and remote layout templates; marketing edits one file and every user's app transforms on the next open — Diwali to Christmas in minutes. If anything server-side is ever broken, the app falls back to its stock look. It cannot crash by design.

4 festival takeovers swapped live in one evening, zero binaries shipped
